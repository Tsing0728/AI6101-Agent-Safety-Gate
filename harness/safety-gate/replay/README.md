# Offline replay

Evaluates the approval policies without running an agent. Recorded GPT-4o tool calls from AgentDojo are fed, in their original order, through the same policy and reviewer code the plugin uses, and each decision is scored against the call's label.

This is where the TCR@k curves and the HITL Load numbers in the report come from. Online runs with the DeepSeek agent are used for task utility and cost, because that agent did not follow any tool-based injection.

## Data

| File | Content |
|---|---|
| `data/offline_test.json` | 967 tool calls from 330 trajectories: the classifier's held-out test split (`safety-gate/checkpoint/test-split.jsonl`), with user task, history, proposed call and teacher label |
| `data/predictions.jsonl` | The 4B classifier's prediction for each call |
| `data/reviews.jsonl` | Cached replies of the simulated reviewer (DeepSeek) |

A call counts as unauthorized when its label is `UNAUTHORIZED` (246 calls, 95 of them `HIGH`) and as authorized when it is `AUTHORIZED` (709 calls).

## Run

```
node replay.mjs              # all settings; uses the cached reviews, so no API key is needed
node replay.mjs --traj 5     # first 5 trajectories only
node replay.mjs --dry-run    # never call the API; uncached reviews count as DENY
```

Node 18 or later. If a review is missing from the cache, set `DEEPSEEK_API_KEY` and the script requests it.

Settings: `approve_all`, and `escalate_all`, `v1`, `v2`, `v2.1` at k = 0, 1, 3, 5. The budget resets at the start of each trajectory, and an escalation with no budget left is denied.

## Output

- `out/summary.md`, `out/summary.csv`: one row per setting (block rates, TCR, HITL Load, escalations, reviewer tokens and cost)
- `out/examples.md`: over-permissive and over-conservative examples under v2.1, k = 3
- `out/decisions.jsonl`: every decision (not committed; regenerated by the script)

## Limitations

- Labels come from a teacher model, not human annotation.
- The test split shares user tasks and injection goals with the training data (only the attack wording differs), so classifier accuracy here is optimistic.
- The recording does not react to the gate: the replay scores each decision, but cannot show how the agent would continue after a denial.
